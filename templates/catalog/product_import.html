Import products from CSV

How it works

  1. Download the template and open it in Excel or Google Sheets.
  2. Replace the example rows with your own products, then save as CSV.
  3. Upload the file below.

Required columns: name, price, stock.
Optional columns: category (must match an existing category name), description, low_stock_threshold, is_published (yes or no).

If any row has a problem, nothing is imported. Fix the file and upload it again. Add product images afterwards from each product's Images button.
